# EarForge

EarForge est une application web pour entraîner l’oreille musicale, progresser régulièrement et travailler aussi bien l’écoute que la voix.

## S’entraîner

- hauteurs, intervalles et degrés ;
- accords, renversements, progressions et cadences ;
- gammes, modes et notes ;
- rythme, pulsation et mesure ;
- mémoire, contour et erreurs mélodiques ;
- reconnaissance d’instruments et de familles instrumentales ;
- chant, imitation de hauteurs et précision de l’intonation.

## Utilisation

L’accueil propose directement la séance du jour. Il est aussi possible de choisir un exercice, de travailler le chant ou de mesurer sa précision. La progression reste consultable séparément et les réglages utiles sont regroupés au même endroit.

EarForge fonctionne au tactile, au clavier et avec les lecteurs d’écran. Les informations importantes ne reposent jamais uniquement sur la couleur ou sur un son.

Le mode mains libres utilise la synthèse vocale du système lorsqu’elle est disponible.

## Données

La progression est conservée localement dans le navigateur et peut être exportée puis restaurée. Le microphone est analysé localement pour les exercices de chant ; aucun enregistrement vocal n’est sauvegardé par EarForge.
