# EarForge

EarForge est une application Web progressive d’entraînement auditif. L’interface reste volontairement simple : une séance du jour ou un mode mains libres. Le parcours, la répétition espacée, les prérequis, la variation des timbres et la difficulté sont calculés localement après chaque réponse.

L’application fonctionne sans compte, sans publicité, sans mesure distante et sans dépendance réseau après la première ouverture.
